# [[React]] - Hooks

Permite que você use estados e outros recursos do React sem escrever um classe. Encapsula funcionalidades e facilita o reaproveitamento da sua lógica.

## Exemplos de Hooks
 - useState: Permite adicionar um variável de estado no componente.
 - useEffect: Utilizando no ciclo de vida do componente e permite trabalhar com side-effects(efeitos colaterais).
